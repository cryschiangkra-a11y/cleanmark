# CleanMark（乾淨文件）

移除 Word 文件嘅水印同隱藏資料，**排版完全唔變**。檔案只喺你部電腦嘅瀏覽器入面處理，唔會上傳去任何地方。

Remove watermarks and hidden data from Word documents, entirely in your browser. Nothing is uploaded.

## 點運作

CleanMark 唔係「刪除水印」，而係**按白名單重新抄寫一份**：

1. 逐個 Word 元素讀原檔
2. 只有白名單入面、數值驗證過嘅排版元素（段落、樣式、表格、目錄、頁碼、章節、方程式、圖片框架等）先會重新寫入一份全新檔案
3. 水印、頁首 logo、作者同軟件資料、編輯紀錄碼、文件 ID、customXml、C2PA 簽章、隱形字元一律唔搬；圖片入面嘅 EXIF、XMP、C2PA 會清走
4. 新檔案整好之後再自我檢查一次，通過先俾你下載

用一份 50 頁、有目錄、方程式同圖片嘅學術報告測試：Word 逐頁比較，新檔同原檔每一頁都一模一樣。

## 檢查同清除

| 類別 | 例子 |
|---|---|
| 可見水印 | Word 內建水印、頁首頁尾嘅圖形同 logo、文字後面嘅圖形 |
| 檔案資料 | 作者、最後修改人、建立軟件、自訂欄位、customXml |
| Content Credentials | C2PA 簽章 |
| 隱形字元 | 零寬度空格、Tag 字元、方向覆寫等（阿拉伯文、波斯文、emoji 需要嘅會保留） |
| 可疑字句 | 例如「由 AI 生成」、「Generated by」，預設保留，由你決定刪唔刪 |
| 可疑字元 | AI 可能用嚟喺文字入面藏記號嘅「睇落正常」字元：<br>• **同形字**：英文字入面夾雜睇落一樣嘅西里爾 / 希臘字母（例如 `Clаude` 嘅 `а`），預設換返英文字母<br>• **異常撇號**：英文字母之間嘅 U+02BC、U+02B9，預設換成正常撇號<br>• **特殊空格**：U+00A0、U+2000–U+200A 等，列出嚟由你決定換唔換（預設唔換，因為好多時係正常排版） |

## 做唔到嘅嘢

- **統計水印**（藏喺用字規律入面，例如 SynthID-Text）：要 AI 公司嘅私人密鑰先驗證到，CleanMark 唔會檢查亦唔會清除
- Word 註解同修訂紀錄唔會保留；圖表同 SmartArt 會變成佔位圖
- 只支援 Word（.docx）

## 安全

- **防壓縮炸彈**：.docx 其實係一個壓縮檔。一個特製嘅細檔案解壓之後可以大到幾 GB，令網頁卡死。CleanMark 會邊解壓邊計實際大細，超過 300 MB 或者內部檔案多過 5,000 個就停止處理（唔會信壓縮檔自己報嘅大細，因為可以作假）
- **圖片**：PNG、JPEG、GIF、BMP、WebP、TIFF 會清走 EXIF、XMP、C2PA、IPTC、AIGC 等資料之後保留；其他格式（例如 EMF）用同尺寸佔位圖

## 私隱

- 網頁設定咗 Content Security Policy（`connect-src 'self'`），瀏覽器層面禁止連去任何外部網址
- 冇任何分析或者追蹤工具

## 使用守則

只可以用喺你有權處理嘅文件。唔好用嚟移除他人嘅版權、機密或者其他權利標記。

## 開發

```bash
npm install
npm run dev      # 本機開發
npm test         # 單元測試
npm run e2e      # 瀏覽器測試（第一次要先行 npx playwright install chromium）
npm run build    # 打包到 dist/
```

### 用 Word 驗證排版（只限有 Microsoft Word 嘅 Mac）

```bash
npx tsx scripts/verify-layout.mts 你的文件.docx
```

會用 Word 將原檔同 CleanMark 新檔都轉成 PDF，用 macOS 內建 PDFKit 逐頁比較畫面，顯示 `IDENTICAL` 或者邊幾頁唔同。
