## 修訂紀錄（2026-10-15）

以下決定取代下文有衝突嘅內容：

1. **只做 Word。** PDF 同 PowerPoint 唔做；`.pptx`、`.pdf` 當唔支援格式。下文有關 PDF、PowerPoint 嘅部分作廢
2. **目標：排版百分百唔變。** 用 Word 將原檔同新檔轉 PDF 逐頁比較，要完全一樣（`scripts/verify-layout.mts`）
3. **輸出器改為「白名單重新抄寫」。** 唔再經內容清單翻譯：逐個 Word 元素讀，只有 `src/core/sanitize/policy.ts` 白名單入面、數值驗證過嘅元素同屬性先會重新寫入一份全新檔案。冇喺白名單嘅一律唔搬，包括 `rsid`、`paraId`、文件 ID、`docVars`、`customXml`、註解、修訂作者、範本路徑。新檔案嘅 relationship、檔名、docProps 全部重新產生。內容清單仍然用嚟出報告同預覽
4. **圖片預設保留**，寫入之前清走 EXIF、XMP、C2PA、文字註解等 metadata；用家可以改用同尺寸佔位圖。EMF 等唔支援清理嘅格式一律用佔位圖
5. **特殊空格：只替換 U+202F。** 全形空格、細空格等係正常排版用嘅（例如圖表目錄），原樣保留
6. **欄位：** 目錄、頁碼、交互參照等白名單欄位保留；其他欄位（例如 `AUTHOR`）清空指令，只保留顯示結果
7. **書籤：** 名稱只准字母、數字、底線（例如 `_Toc123`）
8. **可疑字句預設保留**；方程式按白名單保留；圖片位置用章節名提示
9. **防壓縮炸彈**：解壓時逐段計實際大細，總數上限 300 MB、內部檔案上限 5,000 個；超過就顯示「解壓縮後大得不正常」（錯誤代碼 `unsafeArchive`）
10. **圖片格式**：WebP（只保留影像、透明、動畫、色彩設定資料段）同 TIFF（只保留影像必需標籤，其他標籤資料清零）都可以清理後保留

## 1. 目標

用家將 Word、PowerPoint 或 PDF 拖入網頁，CleanMark 會：

1. **檢查**檔案入面有冇水印同 metadata，並出一份易明嘅報告
2. **重建**一份全新、乾淨嘅檔案，文字同格式跟返原檔，但唔帶任何水印同舊 metadata

重建嘅原理等同「請人睇住原稿重新打一次」：只抽出文字同格式，喺一份空白新檔案入面重新砌出嚟，原檔其他嘢一律唔搬（白名單做法）。

### 1.1 處理範圍

| 水印種類 | 例子 | 第一期 |
|---|---|---|
| 可見水印 | 背景斜字、頁首 logo、PPT 母片圖案、PDF 每頁重複嘅半透明字 | ✅ 檢查 + 清除 |
| Metadata | 作者、建立軟件、時間、自訂欄位、XMP、C2PA | ✅ 檢查 + 清除 |
| 隱形字元 | 零寬度空格、Tag 字元等 | ✅ 檢查 + 清除 |
| 統計水印 | 例如 SynthID-Text，藏喺用字規律入面 | ❌ 無法檢查或清除。報告會明確寫明 |

### 1.2 唔做嘅嘢（第一期）

- 統計水印、OCR（掃描 PDF）、舊格式 .doc / .ppt
- Word 註解 (comments)、PowerPoint 動畫同轉場
- 一次處理多個檔案
- Terminal 版（第二期）

## 2. 輸入同輸出

| 原檔 | 一定輸出 | 可選輸出 |
|---|---|---|
| .docx | .docx | .pdf |
| .pdf | .docx | .pdf |
| .pptx | .pptx | .pdf（每頁一張投影片） |

- 「同時輸出 PDF」選項預設**唔剔**。唔剔就唔載入字型，處理會快好多
- 檔案大小上限：50 MB
- 新檔案嘅 metadata 一律設定成中性內容：作者、標題、公司等欄位留空，建立同修改時間係轉換嗰陣，建立軟件欄唔寫入；如果格式規定一定要有，就填 `CleanMark`。所有套件嘅預設值（例如 `Producer: pdf-lib`）都要逐個覆寫

## 3. 架構

```
原檔 ──▶ ① 讀取器 ──▶ 內容清單 ──▶ ③ 清潔器 ──▶ ④ 輸出器 ──▶ 新檔案 ──▶ ⑤ 自我檢查 ──▶ 下載
   │
   └───▶ ② 檢查器 ──▶ 水印報告
```

| 零件 | 責任 | 輸入 → 輸出 |
|---|---|---|
| ① 讀取器 | 每種格式各一個，將原檔轉成「內容清單」 | 檔案 bytes → `Document` |
| ② 檢查器 | 搵水印、metadata、C2PA、隱形字元、可疑字句、圖片 | 檔案 bytes（+ `Document`）→ `Report` |
| ③ 清潔器 | 清隱形字元，按用家確認刪除可疑字句，按用家選擇處理圖片 | `Document` + 用家選擇 → `Document` |
| ④ 輸出器 | 由空白開始砌新檔案 | `Document` → 檔案 bytes |
| ⑤ 自我檢查 | 用檢查器再檢查新檔案，並清點檔案結構 | 新檔案 bytes → 通過 / 唔通過 + 原因 |

- 檢查器同讀取器互相獨立：就算檢查器漏咗某種新款水印，讀取器都唔會搬佢，因為「內容清單」根本冇欄位裝得落水印
- `src/core/` 唔准用任何瀏覽器專屬 API（例如 DOM、`window`），咁第二期 Terminal 版先可以直接重用

### 3.1 內容清單 (`Document`)

只包括以下內容：

- **頁面設定**：大細、方向、邊界
- **區塊**（按次序）：
  - 段落：標題層級 (0–6)、對齊、縮排、行距、段前段後距離、列表資料（第幾層、有冇編號、編號格式）
  - 表格：每格內容（由區塊組成）、合併儲存格、欄寬、框線
  - 圖片位置：序號、尺寸、位置提示（前面最近嘅標題，冇標題就用前一段文字）；原圖 bytes 另外存放，只有用家揀「保留原圖」先會用
  - 分頁
- **文字片段 (run)**：文字、字型、大細、粗體、斜體、底線、刪除線、顏色、螢光筆顏色、上標 / 下標、超連結網址
- **方程式**：OMML 元素樹，只保留 `m:` 數學元素、`m:t` 文字，同 `m:r` / `m:ctrlPr` 入面嘅基本字型格式（`rFonts`、`b`、`i`、`sz`、`szCs`、`color`）
- **頁首頁尾**：只限段落同表格，冇任何圖形
- **註腳**
- **PowerPoint 專用**：投影片列表，每張包含文字框 / 表格 / 圖片位置，每個有位置、大細、旋轉角度，加講者備註文字

## 4. 讀取規則

### 4.1 Word (.docx)

- 用 JSZip 解壓，讀 `word/document.xml`、`styles.xml`、`numbering.xml`、頁首頁尾、註腳
- 格式按樣式繼承逐層計出最終值：文件預設 → 段落樣式 → 字元樣式 → 直接設定
- 標題：用段落樣式或者大綱層級 (`outlineLvl`) 判斷
- 修訂追蹤：新增嘅保留，刪除咗嘅唔要
- 頁首頁尾：只搬段落同表格文字，所有圖形（VML、DrawingML、WordArt、文字方塊）一律唔搬
- 內文入面嘅文字方塊：抽出文字，變返普通段落
- 圖表、SmartArt：當圖片處理
- 方程式：按白名單原樣保留（見 3.1）。方程式係純數學文字，藏唔到圖形水印；入面嘅隱形字元照樣清
- 註解：唔搬

### 4.2 PowerPoint (.pptx)

- 按 `presentation.xml` 嘅次序讀投影片
- 讀取每張投影片上面嘅文字框、表格、圖片、組合圖形（拆開組合，按原本位置擺返）
- 如果文字框冇自己嘅位置（即係由版面配置或者母片繼承），**只借用**版面配置或者母片上面嘅位置同預設文字格式，佢哋上面嘅內容（圖片、圖案、文字、背景）一律唔搬
- 投影片背景：唔搬，新檔案用白色背景
- 圖表、SmartArt：當圖片處理
- 講者備註：保留文字
- 動畫同轉場：唔搬

### 4.3 PDF

- 用 pdf.js 讀取每段文字嘅位置、字型名稱、大細，再讀繪圖指令攞文字顏色
- 粗體同斜體：由字型名稱（例如 `-Bold`、`-Italic`、`-Oblique`）同字型描述旗標判斷
- 段落：由行距同縮排推斷，將同一段嘅行合併
- 標題：字體明顯大過內文主體大細、而且獨立成行，就當係標題。按大細排列，分配到標題 1–6
- 列表：由行首符號判斷，例如 `•`、`-`、`1.`、`(a)`、`i.`
- 表格：由文字有冇對齊成欄推斷。推斷唔到就退返做普通段落，並喺報告提示用家留意
- 被判斷為水印嘅文字同圖片（見 5.1）唔會放入內容清單
- 冇文字層嘅頁面（掃描圖）：見第 8 節

## 5. 檢查器

### 5.1 可見水印

| 格式 | 規則 |
|---|---|
| Word | 頁首頁尾入面嘅圖形，包括 Word 內建水印（`PowerPlusWaterMarkObject`、`v:textpath`）；擺喺文字後面 (`behindDoc`) 嘅圖形；頁面背景 |
| PowerPoint | 母片同版面配置上面嘅圖片、圖案、文字；投影片背景圖片 |
| PDF | `/Watermark` 註解；標記為 `/Artifact /Watermark` 嘅內容；名稱有「watermark」嘅圖層 (OCG)；同埋符合以下任何兩項嘅文字或圖片：旋轉角度唔係 0° / 90° / 180° / 270°、透明度低過 100%、喺一半以上頁數嘅同一位置重複出現 |

### 5.2 Metadata

- Word / PowerPoint：`docProps/core.xml`、`app.xml`、`custom.xml`、`customXml/` 入面所有資料
- PDF：文件資訊字典 (Info)、XMP
- 報告逐項列出欄位名同內容

### 5.3 C2PA

喺成個檔案入面搜尋 C2PA / JUMBF 簽章，包括壓縮包入面每個細檔案同埋 PDF 附件。

### 5.4 圖片

列出每張圖片嘅序號同位置提示（Word 冇儲存可靠嘅頁數，所以唔顯示頁數）。如果圖片本身帶有 EXIF、XMP 或者 C2PA 資料，就標記「呢張圖帶有標記」。

### 5.5 可疑字句

用一份中英文關鍵字表搜尋內文，例如「由 AI 生成」、「AI 協助」、「人工智能生成」、「Generated by」、「AI-generated」、「ChatGPT」、「Claude」、「Gemini」、「Copilot」。搵到嘅段落會列出嚟俾用家確認，**預設保留**（唔剔「刪除」）。原因：好似學術報告嘅 AI 使用聲明呢類段落可能係規定要保留嘅，應該由用家自己決定。

### 5.6 隱形字元

| 處理 | 字元 |
|---|---|
| 一定清走 | U+200B 零寬度空格、U+202D / U+202E 方向覆寫、U+2060–U+2064、U+FEFF、U+00AD 軟連字號、U+180E、U+E0000–U+E007F Tag 字元 |
| 換成普通空格 | U+00A0 以外嘅特殊空格，例如 U+202F 窄不換行空格、U+2000–U+200A。例外：方程式入面嘅 U+2000–U+200A 同 U+205F 係排版空格，保留 |
| 視乎上下文 | U+200C ZWNJ、U+200D ZWJ：前後係需要佢哋嘅文字（阿拉伯文、波斯文、印度各種文字等）或者 emoji 就保留，否則清走 |
| 視乎上下文 | U+200E / U+200F 方向標記、U+202A–U+202C 方向嵌入：同一段入面有由右至左文字（阿拉伯文、希伯來文等）就保留，否則清走 |
| 視乎上下文 | U+FE00–U+FE0F 異體選擇符：前面係 emoji 或者 CJK 字就保留，否則清走 |

報告會分開顯示「已清除 X 個」同「保留咗 Y 個（語言需要）」。

## 6. 自我檢查

新檔案整好之後、提供下載之前：

1. 用檢查器檢查新檔案，要求所有項目（可見水印、metadata、C2PA、隱形字元）都係零。以下例外，報告會照列：用家揀咗保留嘅圖片同可疑字句、按 5.6 因為語言需要而保留嘅隱形字元
2. **結構清點**：
   - .docx / .pptx：列出壓縮包入面所有細檔案，同輸出器預期嘅清單比較，多咗或者唔同名都當唔通過
   - .pdf：列出所有物件類型，唔准有註解、附件、XMP、圖層 (OCG) 或者 JavaScript
3. 唔通過就唔顯示下載掣，並顯示原因

## 7. 介面（A 簡潔單頁）

- 一次處理一個檔案，所有步驟喺同一頁由上至下排列
- 語言：繁中同 English。預設跟瀏覽器語言，右上角可以切換
- 手機屏幕都要用得到（寬度 360px 起）

### 7.1 未揀檔案

- 頂部：CleanMark 名稱、語言切換
- 拖放區：接受 .docx、.pptx、.pdf，亦可以撳一下揀檔案。下面寫住「檔案唔會離開你部電腦」
- 三個細圖示講解「檢查 → 確認 → 下載」
- 頁底：「做唔到啲乜」說明（統計水印、掃描 PDF 等），以及使用守則（見 9.4）

### 7.2 揀咗檔案之後

1. 檔案資料行：檔名、偵測到嘅語言（第 4 期）、總共搵到幾項嘢、「換檔案」
2. **檢查報告**：逐項列出，撳入去可以睇詳細內容；最尾一行註明統計水印無法檢查
3. **要你確認**：
   - 可疑字句：每句一個「刪除」選項，預設唔剔
   - 圖片：每張揀「佔位框」或者「保留原圖」，另外有「全部用佔位框」/「全部保留」快捷掣。預設全部用佔位框
   - 揀「保留原圖」嘅時候，提示「圖片可能帶有水印或者 metadata，建議重新整過」
4. **預覽新檔案**：用 HTML 顯示清潔後嘅內容清單；用家改選擇之後，即時更新
5. **下載**：「同時輸出 PDF」選項（預設唔剔）→ 撳「清除並下載」→ 進度 → 自我檢查結果 → 下載掣 →「處理另一個檔案」

佔位框嘅樣：同原圖一樣大嘅虛線框，中間寫住「圖片 N：請重新插入」，並用新檔案嘅語言顯示（跟介面語言）。

### 7.3 PDF 輸出嘅語言支援

- 保證：中文（繁簡）、日文、韓文、英文、使用拉丁、希臘、西里爾字母嘅語言
- 份文件入面如果有阿拉伯文、希伯來文、泰文、印度各種文字等，「同時輸出 PDF」選項會停用，並顯示原因（呢啲語言暫時只支援 Word / PowerPoint 輸出）
- 字型只按文件入面實際用到嘅文字載入對應嘅 Noto 字型

## 8. 錯誤處理

| 情況 | 顯示訊息 |
|---|---|
| .doc / .ppt | 請先用 Word / PowerPoint 另存為 .docx / .pptx |
| 其他格式 | 只支援 .docx、.pptx、.pdf |
| 超過 50 MB | 檔案太大，上限係 50 MB |
| 有密碼 | 請先移除檔案嘅密碼 |
| PDF 冇文字層 | 呢個 PDF 係掃描圖片，暫時處理唔到 |
| PDF 部分頁冇文字層 | 照樣處理，報告列出邊幾頁冇文字，嗰幾頁會當圖片處理 |
| 檔案損壞或者解析失敗 | 打唔開呢個檔案，試下用原本嘅軟件重新儲存 |
| 自我檢查唔通過 | 顯示唔通過嘅項目，唔提供下載 |

所有錯誤都唔會令頁面卡死，用家隨時可以「換檔案」。

### 9.2 私隱同效能

- Content Security Policy：`default-src 'self'`，`connect-src 'self'`。網頁唔可以連去任何外部網址，所有資源（包括字型）都由自己網站提供
- 唔用任何分析或者追蹤工具
- 讀取、檢查、輸出全部喺 Web Worker 入面做，主畫面唔會卡

## 10. 測試

- **樣本檔**（`tests/fixtures/`），每個都知道入面有啲乜：
  - Word：內建文字水印、圖片水印、頁首 logo、各種 metadata、自訂欄位、隱形字元、可疑字句、多層列表、合併儲存格表格、修訂追蹤
  - PowerPoint：母片 logo、背景圖、版面配置繼承位置嘅文字框、組合圖形、講者備註
  - PDF：`/Watermark` 註解、斜字半透明重複水印、XMP、多欄表格、純掃描頁
  - 多語言：中英混合、日文、波斯文（含 ZWNJ）、emoji 家庭序列（含 ZWJ）
- **清除測試**：每個樣本處理之後，新檔案通過自我檢查，而且搜尋唔到原本嘅水印文字或者 metadata 值
- **格式測試**：「讀原檔 → 寫新檔 → 讀新檔」，前後兩份內容清單喺支援嘅欄位上要相同
- **隱形字元測試**：清走嘅清走，ZWJ / ZWNJ 喺需要嘅語言同 emoji 入面保留
- **介面測試**（Playwright）：拖入檔案 → 報告出現 → 改圖片選擇 → 下載 → 下載到嘅檔案通過自我檢查
- 開發方式：TDD，先寫測試再寫實作
